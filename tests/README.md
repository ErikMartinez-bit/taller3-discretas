# Pruebas

Pruebas y ejemplos de entrada/salida por ejercicio. Cada archivo
`test_ejercicio_XX.py` importa las funciones del ejercicio correspondiente
en `src/` y corre asserts con al menos 3 casos (incluyendo casos límite).
Se ejecutan de forma independiente:

python tests/test_ejercicio_XX.py

El archivo `grafo_ejemplo_ej4.json` es el grafo de ejemplo usado por el
ejercicio 4 (Dijkstra) cuando se carga desde archivo en vez de desde el
diccionario definido en el código.
